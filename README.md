# Namma-Yantra Share Android App\n\n## Uber for Tractors - Peer-to-Peer Machinery Rental\n\n### Features\n- Equipment listing with location/distance\n- Rental requests with duration/date\n- Price calculator (hourly/daily)\n- Machine health/service status\n- Real-time availability (Firebase)\n- Request status (Pending/Accepted/Declined)\n\n## Setup\n1. Open in Android Studio\n2. Create Firebase project, add google-services.json to app/\n3. Enable Realtime Database/Auth/Maps API\n4. Add dependencies in build.gradle\n\n## Run\n`./gradlew assembleDebug`
