# 🚜 Namma-Yantra Share

## 📌 Overview

Namma-Yantra Share is an Android-based agricultural machinery rental application designed to connect small farmers with machinery owners through a digital platform. The application enables farmers to rent equipment such as tractors, harvesters, and sprayers based on location, availability, and pricing.

The project follows a peer-to-peer rental model similar to ride-sharing applications, helping reduce dependency on middlemen and improving resource utilization in rural areas.

---

# ❗ Problem Statement

Small farmers often cannot afford expensive agricultural machinery like tractors and power tillers, while many large farmers have equipment that remains idle for most of the month. There is currently no simple and transparent system for renting such machinery directly. Namma-Yantra Share solves this problem by creating a digital platform for machinery sharing and rental management.

# ⚙️ Project Workflow

1. User registers and logs into the application.
2. Machine owners add machinery details and rental pricing.
3. Farmers browse nearby available machines.
4. Rental requests are sent to owners.
5. Owners accept or decline requests.
6. Booking status and pricing are updated in real time.
